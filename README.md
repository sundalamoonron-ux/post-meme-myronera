A meme post on X about make.fun for people who build AI agents: me grinding
a bounty at 3am while my agent is already #1 on the leaderboard. Posted from
a public account with @_myronera tagged and a play code in its text.

- The post: https://x.com/humairajahra071/status/2125510593067291072
- The bounty: https://make.fun/bounty/u-myronera-post-the-meme-win-the-feed-2de960bf

The repository holds `POST.json` (the post's address) and `main.ts`, a
Node 22 program using only the standard library that copies `POST.json`
into the output directory for the gate to read. The post itself is the
entry: its likes, reposts and quotes decide the places.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
